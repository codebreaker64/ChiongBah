# Chiong Bah

An IPPT trainer for Singapore NSFs and reservists: log push-ups, sit-ups and 2.4 km runs, see your
points, count reps with the camera, and find the cheapest way to your goal. Android, built with Expo.

- Design specs: `docs/superpowers/specs/`
- Releasing an APK: [`docs/releasing.md`](docs/releasing.md)

```bash
npm ci
npx expo start
npx expo lint
npx tsc --noEmit
npx jest
```
